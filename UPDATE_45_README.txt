NOVA Update 45 — Upright Wire Nuts and Separated Conductors

- Wire nuts in splices are upright, with their closed ends pointing up.
- Individual conductors approach the open mouth from below on separated paths.
- The pigtail is drawn as a distinct curved conductor from the splice to its assigned terminal.
- Saved splices, terminals and labels are unchanged.

Install: Back up your existing project. Extract this full project ZIP into a separate folder; run npm install and npm run dev. Test a splice with two cables and one pigtail.

Notes: Illustration is schematic, not a physically validated connector arrangement. Multiple splice groups in a small device view may still require scrolling or a future zoomable box view.
