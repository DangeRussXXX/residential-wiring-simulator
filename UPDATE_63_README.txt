NOVA Update 63 — Home Run in Device Wiring panel

When inspecting a device cable, other cables entering the same box now appear as expandable, individually interactive diagrams. Panel P1 home runs are shown first and expanded by default. Each has draggable conductors and saved terminal selectors. GFCI LINE/LOAD rear-terminal artwork is retained. No automatic terminations are made.

The home-run diagram appears when the selected cable shares a device box with a saved home run. For a box with only a home run, select the home run from Installed cables.
